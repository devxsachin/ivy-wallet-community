# Why this fork?

The original Ivy Wallet project became archived after development stopped.

Rather than letting one of the best open-source Android finance apps disappear, this repository continues its development.

Our goals are simple:

- Keep Ivy Wallet alive
- Fix bugs quickly
- Modernize dependencies
- Add highly requested features
- Accept community contributions
- Provide long-term maintenance
